# Changelog

All notable changes are listed here. The project follows [Semantic Versioning](https://semver.org/).

## [1.3.2] - 2026-10-18

### Added
- The app lists itself in **Settings > Apps > Installed apps** as soon as it has changed something on the
  computer (browser link, start with Windows, Start menu shortcut), and can be uninstalled from there. The
  entry follows the executable when it is moved or updated; copies installed by winget or Scoop keep the
  package manager's own entry.
- Uninstalling lists what will be removed, stops the other running ChainShot processes, removes everything
  ChainShot added and offers to delete `ChainShot.exe` (with the other files of the release zip and their
  folder when nothing else is in it). Command line: `ChainShot.exe uninstall --delete-exe`.
- The PowerShell module is listed in Installed apps too (*ChainShot PowerShell module*); its uninstaller
  also stops the tray and removes that entry.

### Fixed
- The PowerShell tray appeared as *powershell.exe* in Task Manager > Startup apps. Its shortcuts now start
  `ChainShotTray.exe`, a small launcher compiled at install time from `ChainShotTray.cs` (C# compiler of the
  .NET Framework, part of Windows), shown as *ChainShot* with its icon. Running `Install-ChainShot.ps1`
  again fixes an existing start-at-logon shortcut.

### Security
- CodeQL analysis of the C# app, `chainshot.py`, the extension and the workflows on every pull request and
  every week (Security tab > Code scanning).
- `.oss-scanner/`: build image and threat model for Anthropic's OSS Scanner, checked by CI.

## [1.3.1] - 2026-10-17

### Changed
- The ChainShot app and `chainshot.py` accept the extension published on the Chrome Web Store
  (ID `ejbdnnlgcnogepeclpknfagfhehkhgap`); the app registers the browser link again when a new
  version knows more extension IDs.
- Website: privacy policy, terms of use and legal information pages (English and French); search

- Maintainer procedures (store publishing, code signing application, winget submission) moved out

## [1.3.0] - 2026-10-17

### Added
- **Firefox** version of the extension (Firefox 140+, declares that it collects no data), built with
  `tools/build_extension.py`; the browser link works with Firefox too (app and `chainshot.py`).
- **Full page capture** in the extension: the page is scrolled, captured part by part (fixed headers appear
  once) and stitched; the banner and the journal record the page size and the number of parts.
- **Page archive (MHTML)** next to the screenshot, as its own chained entry (Chromium; optional permission
  asked when enabled). Browser link protocol 2.
- **Scoop** bucket in this repository and **winget** manifests (`Dalkin69.ChainShot`), generated by the
  release workflow; automatic winget submission with a `WINGET_TOKEN` secret.
- **Website** on GitHub Pages, in English and French, with the code signing policy
  (code signing policy page for the SignPath application).
- `ChainShot.exe uninstall` and *Options > Uninstall from this computer*; `Uninstall-ChainShot.ps1` for the module.
- Release assets: `chainshot-extension-firefox-<version>.zip`, `winget-manifests-<version>.zip`.

### Changed
- The app asks before registering the browser link (it was registered silently in 1.2.0).
- The extension uses the `scripting` permission (full page) and optionally `pageCapture` (MHTML).

## [1.2.0] - 2026-10-18

### Added
- **Browser link**: in the extension popup, choose *ChainShot app* to save web captures, notes and the
  tag into the case open in ChainShot, in the same journal as the screen captures and files. Uses Chrome
  native messaging (local only); `ChainShot.exe` and `chainshot.py native-host` implement the same
  protocol ([docs/browser-link.md](docs/browser-link.md)). The app registers the link at startup
  (Options > *Accept captures from the browser extension*); elsewhere `chainshot.py register-browser`.
- **Evidence package** for delivery: one zip with the case, `chainshot.py`, `VERIFY.txt` (instructions,
  seal and journal SHA-256) and `SHA256SUMS.txt`; recorded in the journal. App menu and button,
  `ChainShot.exe package`, `chainshot.py package`, `Export-ChainShotPackage`.
- RFC 3161 seals record the **local clock offset** against the time-stamp authority, with a warning beyond
  one minute.
- App: **filter** for the journal (`Ctrl+L`) and a **preview pane** with the selected capture and its
  details (`F3`); the app follows case and tag changes made by the module or the extension.
- `chainshot.py use` and `tag` (current case and tag shared with the app and the module) and
  `ChainShot.exe use`.
- [PRIVACY.md](PRIVACY.md): no telemetry, the only network request, what is stored where; also the
  privacy policy of the extension in stores. Guide and images for publishing the extension
  and a store package
  `chainshot-extension-store-<version>.zip` in each release.

### Changed
- The extension manifest has a `key` (fixed ID for the browser link) and the `nativeMessaging` permission.
- The extension waits and retries when Chrome's limit of two captures per second is reached.
- `chainshot.py` uses the same journal lock as the app and the module.
- README: screenshots of the app (taken by the CI on Windows), privacy section.

## [1.1.0] - 2026-10-17

### Added
- **ChainShot for Windows (`ChainShot.exe`)**, the new main Windows tool: a single executable
  (.NET Framework 4.8, built into Windows 10 and 11, no installation, no admin rights) with a graphical
  interface to create and open cases, capture the screen, a window or a region (buttons, delay, global
  hotkeys `Ctrl+Alt+P/W/R`), set the tag and the note of the next capture, hash files by drag and drop,
  add notes, verify, seal with an optional RFC 3161 timestamp and open the HTML report. Tray icon with
  notifications, start with Windows, Start menu shortcut with the ChainShot icon, recent cases.
- `ChainShot.exe` command line for scripts: `new-case`, `tag`, `capture`, `add`, `note`, `verify [--json]`,
  `seal [--tsa]`, `report`, `selftest`.
- A fourth implementation of the journal format (C#), checked against the shared vectors and, in CI,
  against `chainshot.py`, the PowerShell module and a local OpenSSL time-stamp authority.
- The app and the PowerShell module share the current case and tag (`%APPDATA%\ChainShot\state.json`).
- Release asset `chainshot-app-<version>.zip`; every CI run also publishes the tested `ChainShot.exe`.

### Changed
- Windows: the HTML report opens in the default web browser, even when `.html` files are
  associated with an editor such as VS Code.
- Windows: the Start menu shortcut and the tray use the ChainShot icon (`chainshot.ico`)
  instead of the PowerShell icon.
- Banners show the capture number next to the journal entry number: `#2 (capture 1)`.
- The PowerShell tray shortcut is now named **ChainShot Tray (PowerShell)**; **ChainShot** in the Start
  menu is the app. The PowerShell package is renamed `chainshot-powershell-<version>.zip`.
- All components share the version number 1.1.0 (checked by `tests/check_versions.py`).

## [1.0.0] - 2026-10-16

First public release.

### Added
- Journal format v1: canonical entries, SHA-256 hash chain covering time, tag and notes, seals
  with journal prefix hash, RFC 3161 timestamps ([specification](https://github.com/Dalkin69/chainshot/blob/main/docs/journal-format.md)).
- `chainshot.py` (Python 3.9+, standard library only): `init`, `add`, `note`, `verify`, `seal --tsa`,
  `report` (HTML), `export-csv`, `tsr-info`; verification of legacy v0 journals (`journal_preuves.csv`).
- PowerShell module for Windows PowerShell 5.1 and PowerShell 7: screen, all screens, window and
  region captures with an evidence banner below the image; tray application with global hotkeys
  (`Ctrl+Alt+P/W/R`); file hashing, notes, verification, seals, HTML report; per-user installer.
- Browser extension for Chromium browsers (Chrome, Edge, Brave): visible tab capture with URL and
  title, case folder written to `Downloads/ChainShot/`, in-browser chain check, `Alt+Shift+S` shortcut.
- Shared canonical vectors and CI on Linux, Windows and macOS, including real Windows captures,
  the tray application and the extension in Chromium.

### Origin
- Grew out of `Capture-Preuve.ps1`, a script written during a digital forensics course.
