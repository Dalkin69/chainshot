Des captures d'écran qui tiennent comme preuves.

Une capture collée dans un rapport ne prouve rien à elle seule. ChainShot enregistre chaque capture avec son heure, son cas et son examinateur, la hache et la chaîne à la précédente : n'importe qui peut ensuite vérifier que rien n'a été modifié, supprimé ou re-daté.

Chaque capture dit ce qu'elle est

ChainShot dessine un bandeau sous l'image, jamais par-dessus : aucun pixel capturé n'est masqué. Les mêmes informations vont dans le journal, protégées par la chaîne de hash.

#12
numéro d'entrée du journal, celui à citer dans le rapport
cas, tag
le cas et la question ou l'étape documentée (P17)
UTC
heure de capture, avec l'heure locale et le décalage dans le journal
examinateur
qui a capturé, sur quel ordinateur
URL, titre
pour les pages web et les fenêtres, enregistrés automatiquement
SHA-256
empreinte du PNG final, inscrite au journal

De la capture à la preuve

  1. Capturer

    Écran, fenêtre, zone ou page web, avec un raccourci depuis n'importe quelle application. Fichiers et notes aussi.

  2. Hacher

    Le SHA-256 de chaque fichier est inscrit dans un journal en ajout seul.

  3. Chaîner

    Chaque entrée est hachée avec la précédente : modifier, supprimer ou réordonner quoi que ce soit casse la chaîne.

  4. Sceller

    Un scellé fige le journal ; une autorité RFC 3161 peut en certifier l'heure. Son SHA-256 va dans le rapport signé.

Un octet change, et ça se voit

Le même cas, avant et après la modification de quelques octets d'une capture. ChainShot re-hache chaque fichier à la vérification, et le vérificateur indépendant fait exactement la même chose.

Un format, quatre outils

Tous écrivent le même journal, testé sur les mêmes vecteurs : commencez un cas dans l'application, ajoutez des pages web depuis le navigateur, automatisez en PowerShell, vérifiez partout.

Télécharger

Application Windows

# winget
winget install Dalkin69.ChainShot

# Scoop
scoop bucket add chainshot https://github.com/Dalkin69/chainshot
scoop install chainshot

winget propose ChainShot après la validation par Microsoft ; Scoop fonctionne dès la première version. Ou téléchargez le zip sur GitHub, vérifiez-le avec SHA256SUMS.txt et lancez ChainShot.exe. L'exécutable n'est pas encore signé : Windows peut demander une confirmation au premier lancement (pourquoi).

Extension navigateur

Les fiches des stores arrivent. En attendant, chargez-la depuis la release : chainshot-extension-*.zip pour Chrome, Edge et Brave (mode développeur, Charger l'extension non empaquetée), chainshot-extension-firefox-*.zip pour Firefox.

PowerShell, Python

pipx install "git+https://github.com/Dalkin69/chainshot#subdirectory=python"

PowerShell : chainshot-powershell-*.zip, puis Install-ChainShot.ps1.

Vous avez reçu un cas ? Vérifiez-le vous-même.

Inutile d'avoir les outils de capture de ChainShot, Python suffit. Un paquet de preuves contient déjà chainshot.py, un VERIFY.txt et le SHA-256 de chaque fichier.

Vos preuves restent les vôtres

  • Aucune télémétrie, aucune statistique, aucun compte, aucune vérification de mise à jour. ChainShot ne se connecte jamais à Internet de lui-même.
  • La seule requête réseau est l'horodatage RFC 3161 que vous demandez, et elle n'envoie que le SHA-256 d'un scellé.
  • Open source sous licence MIT. Les versions sont construites depuis le dépôt public par GitHub Actions, avec leur SHA-256.
  • Ce site n'utilise ni cookie, ni traceur, ni police ou script externe.
