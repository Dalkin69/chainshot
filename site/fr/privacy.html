Politique de confidentialité

Dernière mise à jour : 2026-10-17

ChainShot est un outil forensic : ce qu'il enregistre vous appartient, à vous et à votre dossier, et à personne d'autre. Cette page s'applique à tous les composants (l'application Windows ChainShot.exe, le module PowerShell, chainshot.py, l'extension navigateur) et à ce site. Elle sert aussi de politique de confidentialité de l'extension dans les stores des navigateurs.

En bref

  • Aucune télémétrie, aucune statistique, aucun rapport de plantage, aucun compte, aucune publicité.
  • Aucune connexion automatique. ChainShot ne vérifie pas les mises à jour et ne contacte aucun serveur de lui-même.
  • Tout reste sur votre ordinateur, dans les dossiers de cas que vous choisissez.
  • Open source (licence MIT) : le code peut être lu et audité dans le dépôt public, et les versions sont construites à partir de lui par GitHub Actions, avec leur SHA-256.

La seule requête réseau : l'horodatage RFC 3161, quand vous le demandez

Lorsque vous choisissez Seal + timestamp (application), seal --tsa (ligne de commande) ou un scellé horodaté avant un paquet, ChainShot envoie une requête à l'autorité d'horodatage configurée (par défaut : FreeTSA). Elle contient le SHA-256 du fichier de scellé (une empreinte dont on ne peut rien retrouver), un nombre aléatoire et l'identifiant de l'algorithme. Aucune capture, aucun fichier, aucune note, aucun nom de cas ni aucune donnée personnelle n'est envoyé. La réponse signée est conservée dans le cas. Cette autorité a ses propres conditions et sa propre politique de confidentialité.

Les liens du menu Aide de l'application ouvrent ce site ou le dépôt dans votre navigateur ; ChainShot lui-même n'envoie rien.

Extension navigateur

Données collectéesAucune. L'extension n'a pas de serveur et n'envoie rien sur le réseau.
Ce qu'elle captureLa partie visible de l'onglet actif, ou la page entière, uniquement quand vous cliquez sur Capture tab ou utilisez son raccourci, avec l'URL et le titre de la page ; une copie MHTML de la page si vous activez Page archive.
Où ça vaVotre dossier Téléchargements (ChainShot/<cas>/), ou, si vous choisissez ChainShot app, le cas ouvert dans ChainShot sur le même ordinateur, par un canal local (native messaging).
Stocké dans le navigateurLe journal des cas créés dans le navigateur, le tag et la prochaine note, sur cet ordinateur uniquement.
PermissionsactiveTab (l'onglet affiché, après votre clic), scripting (page entière : faire défiler la page puis la rétablir), downloads (écrire les fichiers du cas), storage (journal et réglages), nativeMessaging (l'application ChainShot sur cet ordinateur, seulement si vous la choisissez), pageCapture en option (archive MHTML, demandée quand vous l'activez). Aucune permission sur les sites : l'extension ne peut pas lire les sites d'elle-même.

Application Windows et module PowerShell

  • Les réglages sont stockés dans %APPDATA%\ChainShot : cas et tag courants, préférences, manifestes du lien navigateur.
  • Valeurs de registre, pour l'utilisateur courant uniquement et seulement à votre demande : démarrage avec Windows (HKCU\Software\Microsoft\Windows\CurrentVersion\Run) et lien navigateur (HKCU\Software\<navigateur>\NativeMessagingHosts\com.chainshot.host, demandé au premier démarrage). Options > Uninstall from this computer ou ChainShot.exe uninstall les supprime toutes.
  • Les captures contiennent ce qui est à l'écran et peuvent inclure des données personnelles. Conservez les dossiers de cas sur des supports que vous maîtrisez et appliquez les règles de votre organisation sur les preuves et les données personnelles.

Ce site

Aucun cookie, aucun traceur, aucune statistique, aucune police ni aucun script externe. Le site est hébergé par GitHub Pages : comme tout hébergeur, GitHub traite des données techniques comme votre adresse IP pour servir et protéger le site ; voir la déclaration de confidentialité de GitHub.

Vos droits et contact

L'auteur de ChainShot ne reçoit ni ne conserve aucune donnée vous concernant. Pour toute question, ouvrez une issue sur GitHub ; problèmes de sécurité : signalement privé.
